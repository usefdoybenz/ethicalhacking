Subida de Web Shell

Bypass de Filtros y Ejecución Remota de Código

¿Qué es una Web Shell?

Una web shell es un script malicioso subido a un servidor web que permite ejecutar comandos remotamente. Se utiliza para RCE, exfiltración y movimiento lateral tras comprometer funcionalidades de upload.

Vectores de Ataque

  • Validación débil de extensiones
  • Confianza en Content-Type manipulable
  • Subidas en directorios ejecutables
  • Falta de análisis de contenido real

Técnicas de Bypass

Extensiones y MIME
# Extensiones dobles shell.php.jpg # Case variations shell.PHP # Content-Type forzado curl -F "file=@shell.php;type=image/jpeg" target/upload

Mitigaciones

  • Allowlist estricta de extensiones
  • Validación MIME real del contenido
  • Almacenamiento fuera del docroot
  • Deshabilitar ejecución en directorios upload
Apache .htaccess
php_flag engine off RemoveHandler .php .phtml ForceType application/octet-stream
