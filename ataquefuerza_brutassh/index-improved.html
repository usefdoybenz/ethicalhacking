Ataque de Fuerza Bruta SSH

Técnicas de pentesting para servicios SSH con Hydra y NetExec

¿Qué es un Ataque de Fuerza Bruta SSH?

Definición: Un ataque de fuerza bruta SSH es una técnica de ciberataque en la cual un atacante intenta descubrir credenciales de acceso mediante la prueba sistemática y automatizada de múltiples combinaciones de nombres de usuario y contraseñas hasta encontrar una combinación válida.

En el contexto del protocolo SSH (Secure Shell), este tipo de ataque se centra en explotar el puerto 22 (puerto estándar de SSH), que es utilizado para establecer conexiones remotas seguras entre dispositivos a través de una red.

Características del Puerto SSH 22

  • Protocolo: SSH (Secure Shell)
  • Función: Acceso remoto seguro y transferencia de archivos
  • Encriptación: Utiliza cifrado para proteger la comunicación
  • Autenticación: Basada en credenciales o claves públicas/privadas

Herramientas para Ataques de Fuerza Bruta

Hydra
Herramienta de fuerza bruta rápida y versátil que soporta múltiples protocolos incluyendo SSH, FTP, HTTP, y más.
NetExec
Sucesor de CrackMapExec, diseñado para entornos empresariales con capacidades avanzadas de red.
Medusa
Herramienta de fuerza bruta paralela y modular con soporte para múltiples servicios de red.
Ncrack
Scanner de credenciales de red de alta velocidad desarrollado por el equipo de Nmap.

Preparación de Diccionarios

Para ejecutar un ataque de fuerza bruta efectivo, es fundamental contar con diccionarios de usuarios y contraseñas bien estructurados:

Fuentes de Información para Usuarios

  • Páginas web corporativas: Secciones de "Nuestro equipo" o "Staff"
  • Redes sociales: LinkedIn, Twitter, perfiles profesionales
  • Reconocimiento OSINT: Información pública disponible
  • Convenciones comunes: admin, administrator, root, user, etc.

Diccionarios de Contraseñas Populares

  • rockyou.txt: Incluido por defecto en Kali Linux
  • SecLists: Colección amplia de diccionarios especializados
  • Contraseñas por defecto: Credenciales predeterminadas de fabricantes

Ejemplos Prácticos

Ejemplo 1: Ataque con Listas Personalizadas - HTB Servenom

En la máquina Servenom (10.10.10.184) de Hack The Box, identificamos el puerto 22 SSH abierto. Procedemos con un ataque utilizando listas personalizadas:

Comando Hydra
hydra -L users.txt -P passwords.txt ssh://10.10.10.184

Explicación del comando:

  • -L users.txt: Lista de usuarios a probar
  • -P passwords.txt: Lista de contraseñas a probar
  • ssh://10.10.10.184: Objetivo SSH
Ejemplo 2: Usuario Específico con Diccionario - HTB Writer

En la máquina Writer (10.10.11.101) de HTB, identificamos el usuario potencial "kyle". Realizamos un ataque dirigido utilizando el diccionario rockyou.txt:

Comando Hydra
hydra -l kyle -P /usr/share/wordlists/rockyou.txt ssh://10.10.11.101

Explicación del comando:

  • -l kyle: Usuario específico (minúscula para un solo usuario)
  • -P rockyou.txt: Diccionario de contraseñas popular
Ejemplo 3: Entorno Empresarial con NetExec - HTB Wifinetic

En entornos empresariales, NetExec ofrece funcionalidades avanzadas. Ejemplo contra Wifinetic (10.10.11.247):

Comando NetExec
netexec ssh 10.10.11.247 -u users.txt -p passwords.txt

Ventajas de NetExec:

  • Detección automática de credenciales válidas
  • Mejor manejo de errores y timeouts
  • Integración con otros protocolos de red
  • Reporting más detallado de resultados

Medidas de Protección

Importante: Como profesionales de ciberseguridad, también debemos conocer las contramedidas para proteger los sistemas SSH.

Técnicas de Defensa Recomendadas

  • Autenticación por claves: Deshabilitar autenticación por contraseña
  • Fail2ban: Bloqueo automático tras intentos fallidos
  • Rate limiting: Limitar intentos de conexión por minuto
  • Puerto no estándar: Cambiar del puerto 22 por defecto
  • Firewalls: Restringir acceso por IP origen
  • 2FA: Autenticación de dos factores
  • Monitoreo: Logs y alertas de intentos de acceso

Consideraciones Éticas y Legales

Advertencia Legal: Los ataques de fuerza bruta solo deben realizarse en:

  • Sistemas propios o con autorización explícita
  • Laboratorios de práctica autorizados (HTB, TryHackMe, etc.)
  • Entornos de pentesting contratados legalmente

El uso no autorizado de estas técnicas puede constituir un delito según las leyes locales e internacionales.

Optimización de Ataques

Parámetros Avanzados de Hydra

Opciones de Rendimiento
# Ajustar número de hilos paralelos hydra -t 16 -l admin -P rockyou.txt ssh://target # Establecer timeout personalizado hydra -w 30 -l admin -P rockyou.txt ssh://target # Modo verbose para debugging hydra -v -l admin -P rockyou.txt ssh://target

Consideraciones de Rendimiento

  • Hilos (-t): Balance entre velocidad y detección
  • Timeout (-w): Ajustar según latencia de red
  • Pausas: Evitar bloqueos por rate limiting
  • Recursos del sistema: Monitorear CPU y memoria
